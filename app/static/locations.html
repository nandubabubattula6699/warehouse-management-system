4. Deactivate empty Part 2 rows (qty 0)

Each row gets a recorded DEACTIVATE movement with your name. Rows with stock are never included, Allbirds never. Rows at spots that no longer exist are always included. Rows at 0 at spots that still exist (e.g. "to be counted") are only included when you tick them.

5. Link Part 2 stock to locations

Matches each active Part 2 row to its spot (row/section/level → code). Each link is a recorded 0-pc LOCATION_LINK movement. Not possible while any row with stock has no spot.
